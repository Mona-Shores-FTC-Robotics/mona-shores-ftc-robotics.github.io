# mona-shores-ftc-robotics.github.io

The team's GitHub Pages home. It holds only redirects:

- **https://mona-shores-ftc-robotics.github.io/** opens the Visualizer.
- **`/visualizer/`, `/VISUALIZER/` or any other capitalisation** opens the Visualizer too. Pages
  addresses are case-sensitive, and the Visualizer's real address is `/Visualizer/` (its repo's
  name); `404.html` forwards the rest, keeping any `#gh=...` link to an Auto.

The Visualizer itself is published from the
[Visualizer repo](https://github.com/Mona-Shores-FTC-Robotics/Visualizer).
